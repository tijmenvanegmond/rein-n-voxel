## Quick Start

The complex mob system transforms simple wandering entities into a living ecosystem with:

- **Life Mechanics**: Health, hunger, starvation, and death
- **Dynamic Behavior**: Food seeking, eating, combat, and reproduction
- **Visual Feedback**: Real-time health bars and status indicators
- **Performance**: Multithreaded processing for large populations
- **Extensibility**: Modular design for easy expansion

## Key Features

### 🧬 Biological Simulation
- Realistic hunger and starvation mechanics
- Health regeneration when well-fed
- Death and carrion creation
- Type-specific biological parameters

### 🍃 Food Ecosystem
- Procedural food spawning around player
- Multiple food types with preferences
- Terrain-aware placement
- Carrion from dead mobs

### ⚔️ Combat System
- Faction-based hostility
- Threat assessment and response
- Damage types and armor
- Combat state management

### 🚀 Performance Optimized
- Multithreaded mob processing
- Configurable thread pools
- Performance metrics and monitoring
- Scalable to hundreds of mobs

### 🎨 Visual Polish
- Dynamic health bars above mobs
- Status-based visual changes
- Real-time UI updates
- Camera-aware positioning
